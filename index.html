Networking and gRPC for Mojo

Five packages that cover sockets, TLS, HTTP/2, protobuf, and gRPC. Official gRPC interop 84/84, h2spec 146/146, protobuf conformance 1476/1476.

Install

pixi init my-app && cd my-app
# pixi.toml channels:
#   https://conda.modular.com/max
#   https://repo.prefix.dev/modular-community
#   conda-forge
pixi add grpc-mojo   # or mojo-net / mojo-tls / mojo-http2 / protomojo

The stack

  • mojo-net — TCP, UDP, DNS, Unix sockets, poller
  • mojo-tls — TLS 1.2/1.3 over libssl
  • mojo-http2 — HPACK and HTTP/2
  • protomojo — proto3 binary, JSON, protoc-gen-mojo
  • grpc-mojo — unary and streaming RPCs over h2c, TLS, Unix

Unary RPC

Generate stubs, serve, call. Full walkthrough: docs/GETTING_STARTED.md. 

python3 -m grpc_tools.protoc -I. \
  --plugin=protoc-gen-mojo=$(command -v protoc-gen-mojo) \
  --mojo_out=. echo.proto

Limits to know

PollingServer overlaps connection I/O on one thread. Handlers stay serial. A streaming handler stalls every other connection until it returns. Scale-out is processes, not threads.
